# Portfólio | Luana

Meu espaço na web para apresentar quem sou, meus projetos e minha trajetória em tecnologia.

Este é meu portfólio pessoal: um currículo digital interativo que reúne experiências, habilidades, estudos e projetos nas áreas de desenvolvimento, UX/UI Design e dados.

A proposta é unir uma apresentação profissional a uma identidade visual criativa, com uma estética delicada, animações e pequenas interações que tornam a navegação mais interessante.
